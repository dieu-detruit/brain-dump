# Watch操作モック

リポジトリのルートから起動します。Appleアカウント・Node.js・API接続は不要です。

```sh
python3 -m http.server 5180 --bind 127.0.0.1 --directory docs/previews
```

ブラウザーで http://localhost:5180/watch.html を開きます。
`watch.html` を直接ブラウザーで開くこともできます。

- 作業・切り替え: 「続けている」で回答し、時計内をスクロールして別Threadへ切り替えます。
- まだやっている？: 通知から回答する流れを試せます。「回答済み」はモックの説明表示です。実機の通知表示とは異なります。
- Webと接続（初回のみ）: 接続コードの表示と接続後の画面を確認できます。コードは実際には使えません。
- 通信失敗を試す: 失敗時には作業を変更せず、成功とも表示しません。チェックを外すと15秒以内の自動更新で復帰します。「再試行」でも再取得できます。

これは実装済みSwiftUI画面の操作をHTMLで近似したモックです。watchOSシミュレーターではありません。
実データ・認証情報は使用せず、APNs配送・バックグラウンド動作・実機のレイアウトは検証できません。
ネットワーク通信・データ保存は行わず、再読み込みすると初期状態に戻ります。

「待機中」はdelegationなし、「進行中」はAI・他の人への委譲ありというWeb版と同じ分類です。
画面表示中は15秒ごとにダミーのWeb状態を自動取得します。「Webでの切り替えを再現」で変更の反映を試せます。
通常は更新ボタンを表示しません。色はWebの生成り `#f3f0e8`、文字 `#24231f`、オレンジ `#e46945` に合わせています。
